🔄 Guía de Restauración del Sistema
Pasos para recuperar el sistema en caso de falla o cambio de equipo
🕓
Backup automático activo El sistema crea una copia de seguridad automáticamente de lunes a viernes a las 4:00 PM en Google Drive. Se conservan los últimos 30 backups.
0 Requisitos previos (instalar en el PC nuevo)
  • Python 3.10 o superior — en python.org/downloads — marcar ✅ "Add Python to PATH" durante la instalación
  • Git — en git-scm.com/download/win
  • Google Drive para escritorio — en drive.google.com/drive/download — iniciar sesión con la cuenta de la oficina para que monte la unidad G:
1 Obtener el código fuente

Abre una terminal (CMD o PowerShell) y ejecuta:

git clone https://github.com/jdbarajass/SDS_OCDI.git cd SDS_OCDI
2 Instalar dependencias
pip install -r requirements.txt
3 Restaurar la base de datos y archivos de referencia

3.1 — Abre esta carpeta en Google Drive y ordena por fecha (más reciente primero):

G:\Mi unidad\5) DOCUMENTOS PARA CONSEGUIR TRABAJO\Simo\Soportes_SDS\BACKUP_APP_OCDI\Backup_Automatico_OCDI\

3.2 — Cada archivo ZIP contiene:

🗄️
ocdi.db
Base de datos completa — expedientes, SDQS, correspondencia, sala, autos, usuarios
📄
Tipologias_Json.txt
Catálogo de tipologías disciplinarias
📄
EntidadesDependencias_Json.txt
Catálogo de entidades y dependencias
⚠️ Descomprime el ZIP más reciente y copia los tres archivos según se indica abajo.

3.3 — Copia ocdi.db a la carpeta data\ del proyecto:

SDS_OCDI\data\ocdi.db

Si la carpeta data\ no existe: mkdir data

3.4 — Copia los archivos JSON a la raíz del proyecto:

SDS_OCDI\Tipologias_Json.txt SDS_OCDI\EntidadesDependencias_Json.txt
4 Arrancar el servidor
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

Abre el navegador en: http://localhost:8000

Para acceso desde otros equipos en la red: http://192.168.X.X:8000 (usa la IP local del nuevo PC)

5 Reactivar el backup automático
  • Haz doble clic en configurar_tarea_backup.bat (en la raíz del proyecto)
  • El backup volverá a correr automáticamente de lunes a viernes a las 4:00 PM
